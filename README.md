
# Experiment 1: Student CRUD REST API

## Aim
To develop a simple backend application using Node.js and Express with CRUD REST APIs.

## Technologies Used
- Node.js
- Express.js
- Postman

## API Endpoints

| Method | Endpoint | Operation |
|---|---|---|
| GET | /students | Retrieve students |
| POST | /students | Add student |
| PUT | /students/:id | Update student |
| DELETE | /students/:id | Delete student |

## Execution
1. Initialize project using npm init -y.
2. Install Express using npm install express.
3. Implement CRUD routes in server.js.
4. Start server using npm start.
5. Test all endpoints using Postman.

## Result
Successfully developed and tested a Student CRUD REST API using Node.js and Express.
