EXPERIMENT 2: GIT AND GITHUB COMMANDS

1. git --version  - Check Git version
2. git init       - Initialize a repository
3. git status     - Check repository status
4. git add        - Stage files for commit
5. git branch branch-name
   Creates a new branch.

6. git switch branch-name
7. git merge branch-name
   Merges another branch into the current branch.

8. git remote add origin URL
   Connects a local repository to a remote repository.

9. git remote -v
   Displays remote repository URLs.

10. git push -u origin main
    Pushes the main branch to GitHub.

11. git pull
    Downloads and integrates remote changes.

12. git clone URL
    Copies a remote repository to the local system.
   Switches to an existing branch.
